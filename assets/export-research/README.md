# Rail Island 导出依据

本目录保留本项目使用的三份作者发布模块（`published/`）、上游MIT许可和`export-manifest.json`。模型输出按作者官方页面声明采用CC0；两类许可分别适用。

上游仓库：https://github.com/rail-island/rail-island-factory

获取与导出过程见 [本项目记录](../../docs/railisland-export.md)，复现脚本为 `scripts/export-railisland.mjs`。清单记录发布日期、模块SHA-256、默认参数、Three.js导出版本与CRH380A网页导出比对。

调研下载的其余上游源文件仅保留在本地，并由`.gitignore`排除，不参与本项目构建。
