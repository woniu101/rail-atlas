## 坐标与归一化

六个模型的 `Sketchfab_model` 根节点均带有绕 X 轴 -90° 的四元数 `[-0.70710678, 0, 0, 0.70710678]`。使用 GLTFLoader 或 NodeIO 加载后的世界坐标已经是 **Y 向上**。不能只看原始 POSITION accessor 再额外转一次 X，否则机车会侧躺。

仅 HXD2 在加载后沿 Z 轴展开；其余五个模型沿 X 轴展开。将 HXD2 外包组绕世界 Y 轴 +90° 可以统一为 X 长轴。正负号可根据希望看到的车头和车身侧面选择，不影响归一化后的几何尺寸。

数值为 GLB 原始单位，文件未提供足以证明其与米之间关系的单位声明，不应直接当作真实车辆尺寸。建议每台车按最大长度缩放至统一展示长度，再将 X/Z 中心移至零、Y 最低点移至地面。HXD3D 的最高点包含升起的受电弓，所以其包围盒比其他电力机车更高；不应把它当作多余离群点裁掉。

包围盒计算遍历每个网格的实际索引三角形顶点，应用完整父子层级世界变换，并忽略 POINTS/LINES。线段是独立图元，可以在网页优化版本移除以减少绘制调用；但应保留原文件作为来源副本。

## 材质与照明

原始材质全部 `metallicFactor = 0`、`roughnessFactor = 0.6`、`doubleSided = false`，以基础颜色与贴图表现涂装，未发现需要额外解码的专用材质扩展。推荐先保持材质与色彩空间，只用环境光和方向光改善可见性。不要全局改成高金属度，否则车体在缺少 HDR 环境贴图时可能变黑。

玻璃透明材质应保留：

- DF4D：玻璃 alpha 约 0.651；另有 alpha=1 但通过纹理透明的栅网材质。
- HXD2、HXD3B：玻璃 alpha 约 0.502。
- HXD3D：两组玻璃 alpha 约 0.890 和 0.502。
- SS9：包含 alpha 约 0.502、0.678、0.129、0.800 的透明材质。
- ND5：没有声明 BLEND 的材质。

绘制调用是原模型的三角网格数量，未计入阴影通道、透明双面绘制或后期处理等额外工作。优化时可做材质去重、网格合并和面数简化，但保持透明玻璃、纹理与线框处理的差异。

## 部件与热点

网格以 `Material2`、`Material3` 等重复名字组织，模型内部没有可靠命名的受电弓、转向架、车轮或车门节点。`Bogie_Spring` 等只是材质名，不代表可独立控制的机械部件。不能通过节点名直接实现升弓或转向架动画。

因此本次不把任何未核实坐标写作真实部件位置。热点可在最终归一化模型的浏览器画面上用射线拾取设定，保存到每台车自己的配置，并通过正面、侧面及顶部视角核对；不要给所有车型套用同一组坐标。

### HXD3D 顶部几何校准

为辅助浏览器内人工校准，另行收集 HXD3D 最高约 5% 高度内的三角形顶点，去重后得到 1,686 个顶点。沿 X 轴只形成一个连续簇，范围为 X `[-98.669, -74.999]`、Y `[247.035, 257.883]`、Z `[-262.954, -189.159]`。其中最高 16 个顶点的包围盒中心为：

```text
raw world: [-86.833946, 257.881744, -226.163002]
```

这是唯一升起受电弓的顶部接触头候选，需在渲染画面上确认。以整车包围盒中心 `c = [167.204117, 131.598401, -226.836952]`，缩放 `s = 6 / 905.578827 = 0.0066255966`：

```text
整车中心归零，长度6： (raw - c) * s
热点候选：[-1.683154, 0.836702, 0.004465]

X/Z中心归零、Y落地，长度6：
x = (raw.x - c.x) * s
y = (raw.y - 5.314142) * s
z = (raw.z - c.z) * s
热点候选：[-1.683154, 1.673411, 0.004465]
```

以上为几何校准值，不是所有车型通用坐标；如果场景额外旋转、移动或改变统一长度，热点必须跟随同一变换。转向架的低位几何混有排障器、车底设备与轮对，无法仅从顶点分布可靠区分机械部件，因此本次不输出转向架热点坐标。
